# HUB TJIndoor — TVStudio

- **Cliente:** TVStudio
- **Playlist:** Playlist TVStudio
- **Orientação:** Vertical
- **Quantidade inicial de referência:** 5 itens

## Organização das mídias

- As mídias pertencem exclusivamente a esta playlist.
- A quantidade de itens é dinâmica e pode aumentar ou diminuir.
- A ordem e a duração são definidas pelo Painel TJIndoor.
- Preservar os nomes originais dos arquivos.
- Cada publicação deve manter os vínculos entre o cliente, a playlist e suas mídias.
- O manifesto publicado deve refletir os itens reais da playlist.

## Status

Estrutura inicial do HUB. A integração automática de publicação e o armazenamento independente do PC ainda precisam ser implementados e validados.
